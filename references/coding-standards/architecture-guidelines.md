# 通用架构约束（提炼版）

来源：12-Factor App（12factor.net）与业界通行实践。所有模块适用。

## Rule 级

- 分层清晰（接口/业务/数据访问），依赖单向向下，禁止反向与跨层直连
- 跨模块调用只走公开接口，不 import 对方内部实现
- 配置外部化（环境变量/配置文件），代码零硬编码环境值；
  密钥不入库，提供 .env.example 或配置模板
- 日志：分级合理、结构化优先、关键链路带 traceId、禁止打印密码/token/身份证等敏感字段
- 错误处理：统一错误类型或错误码，不吞异常，失败要能定位（上下文充分）
- 输入校验前置；外部数据一律不可信
- 依赖版本锁定（lock 文件），引入新依赖需说明理由

## Advice 级

- 服务无状态化，支持水平扩展
- 健康检查端点、关键指标（QPS/延迟/错误率）与慢查询日志
- 接口变更保持向后兼容；废弃走公告期
